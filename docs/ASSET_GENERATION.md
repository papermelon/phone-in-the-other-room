# Generated Asset Notes

The public repository uses redacted placeholder artwork in `Assets.xcassets`.

The original prototype artwork was generated with an AI image-generation workflow and then intentionally redacted before publication. The checked-in asset catalog is the source of truth for this open-source version.

## Workspace Assets

- `OllieKeyArt`: in-app focus pasture/key-art backdrop.
- `OllieAppIcon`: app icon source image.
- `OllieMascot`: shared iPhone/Watch mascot image.
- `RewardLetter`, `RewardTennisBall`, `RewardRibbon`, `RewardSheepBadge`, `RewardFieldMap`, `RewardPostcard`, `RewardTrophy`, `RewardMuddyPaw`, `RewardStick`, `RewardOllieMail`: cropped reward collectibles from the generated reward sheet.

## Prompt Notes

The detailed private art prompts are not included in the public repository. Use the asset names above as integration points and replace the placeholder images with original artwork for your own app.
